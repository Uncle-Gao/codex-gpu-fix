# 失败方案汇总

## 完全不生效的

| 方案 | 详情 | 为什么失败 |
|------|------|-----------|
| `--use-angle=metal` | 强制 Metal 图形 API | Metal 切换不影响合成器 IOSurface 路径，此 bug 在合成层不在渲染层 |
| `--enable-features=Metal` | Chromium 特性开关 | 同上 |
| `--disable-gpu-rasterization` | 禁用 GPU 光栅化 | bug 在合成器纹理共享，光栅化阶段不受影响 |
| `--disable-native-gpu-memory-buffers` | 禁用原生 GPU 内存缓冲 | 理论上有关系，但此 flag 不覆盖 IOSurface 路径 |

## 有反应但不正确的

| 方案 | 效果 | 为什么不行 |
|------|------|-----------|
| `--disable-blink-features=CSSBackdropFilter` | 白色区域变纯白 | 在引擎层面禁用 backdrop-filter，但 CSS 属性被完全移除后元素回退到不同渲染路径，产生不同视觉 bug |
| `--in-process-gpu` | 修复但卡顿 | GPU 和渲染进程合并后 IOSurface IPC 不再需要，但因共享主线程导致明显 UI 延迟 |
| 全局 `border-radius: 0` | 白色区域消失 | 副作用太粗暴——所有圆角都没了 |

## 技术上不可行

| 方案 | 阻碍 |
|------|------|
| 修改 `app.asar` 注入 CSS | Electron AsarIntegrity 校验，标准 shasum 无法算出匹配 hash |
| `--preload` CLI flag | Electron 没有这个命令行参数，preload 是 webPreferences 的 JS 选项 |
| 浏览器 DevTools 远程调试 | `chrome-devtools-frontend.appspot.com`(HTTPS) 不能连接 `ws://` WebSocket (Mixed Content) |
| `NSSupportsAutomaticGraphicsSwitching` 强制独显 | 触发钥匙串弹窗，且不一定保证使用独显，bug 仍在 |

## 效果无改善的

| 方案 | 详情 |
|------|------|
| `clip-path` 替代 `border-radius` | 对所有带 border-radius 的元素添加 `clip-path: inset(0 round Xpx)`，圆角渲染质量无改善 |
